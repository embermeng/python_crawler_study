scrapy的工作流程：
1. 引擎 将 爬虫 中起始的url构造成request对象，并传递给 调度器（队列）
2. 引擎 从 调度器 中获取到request对象，然后交给 下载器
3. 由 下载器 来获取页面源代码，并封装成response对象，并返回给 引擎
4. 引擎 将response对象传递给 爬虫，由 爬虫 对数据进行解析，并返回给 引擎
5. 引擎 将解析后的数据传递给 管道 进行数据持久化保存，或进一步的数据处理
6. 在此期间，如果从 爬虫 中提取到的并不是数据，而是子页面url，就重复以上步骤

引擎（engine）：scrapy的核心，所有模块的衔接，数据流程梳理
调度器（scheduler）：本质上是一个队列，里面存放将要发出的请求，它决定了下一步要去爬哪个url，通常可以在这里对url进行去重操作
下载器（downloader）：就是一个发送网络请求的模块
爬虫（spider）：这是我们要写的第一个部分的内容，负责解析下载器返回的response对象，从中提取数据
管道（pipeline）：这是我们要写的第二个部分的内容，负责数据的存储和各种持久化操作



创建scrapy项目的步骤：
1. 创建项目：
    scrapy startproject 项目名称

2. 在项目根目录创建爬虫：
    scrapy genspider 爬虫名字 允许的域名（如4399.com）

3. 可能需要修改start_urls，修改成需要抓取的那个页面

4. 对数据进行解析，在spider里面的parse(response)方法中进行解析

    需要注意，默认xpath()返回的是Selector对象，需要用extract()提取数据

    extract() 返回列表

    extract_first() 返回第一个数据

	yield 返回数据 -> 把数据交给管道进行持久化存储

5. 在管道中完成数据的存储

6. 设置 settings.py，将管道进行生效设置

   ```python
   ITEM_PIPELINES = {
       # key 是管道的路径
       # value 是管道的优先级，数越小，优先级越高
       "game.pipelines.GamePipeline": 300,
       "game.pipelines.NewPipeline": 299,
   }
   ```

7. 运行爬虫

   scrapy crawl 爬虫名字
